## 0. 一句话、标题、摘要

**一句话：** 小模型 agent 自我进化时，失败轨迹信息最多却最难用。我们用一个冻结的、跨领域的 3B 错误归因器找到失败的关键一步，让 agent 自己带着事后信息给出改法，再用**一步**环境反馈验证，只保留少量可信的纠正，加上自身成功回放来训练。不需要更强的老师、不需要 rollout、不需要新标注，全程一个 3B 骨干。

**暂定标题（二选一）：**
- *Fix the Step, Not the Trajectory: Efficient Self-Evolving LLM Agents with Environment-Verified Self-Corrections*
- *Learning Where You Failed: Efficient Self-Evolution of Small Agents via Transferable Failure Attribution*

**摘要草稿（英文，数字随结果更新）：**
> Self-evolving LLM agents improve from their own experience, but small agents mostly learn from their successes. Turning a failed trajectory into a training signal requires knowing *which* step went wrong and *what* should have been done instead, which existing methods obtain with large-scale online RL, Monte-Carlo rollouts, expert demonstrations, or a stronger teacher. We propose a round-based self-evolution procedure that converts failures into a small number of environment-verified step corrections. A frozen 3B failure attributor, trained once on public multi-agent failure logs from other domains, locates the decisive step of each failure. The agent itself, conditioned on hindsight of the failed episode and the attributor's diagnosis, proposes alternative actions at that step. A single environment step, scored by the change in goal progress, decides which corrections to keep. The agent is then trained on the top 20% of corrections plus replay of its own successful steps. On ALFWorld, a 3B agent improves from 416 to 537 to 561 of 774 games over two rounds, each round significant under a paired test. With the same number of environment episodes it outperforms rejection-sampling fine-tuning, rollout-verified correction, and unverified self-distillation, while using about 150–180 training examples per round and no model larger than the agent.

## 1. 动机（Motivation）

### 1.1 背景：自进化的小模型 agent
- **自进化（self-evolving）：** agent 反复执行"用当前模型在环境里收集经验 → 从经验里产生训练信号 → 训练 → 用新模型再收集"，不依赖新的人工示范。
- **小模型（3B 级）：** 部署最便宜，但起点弱、失败多。
- **核心问题：** 失败轨迹里信息最多，怎么把它们**便宜地**变成可靠的训练信号？

### 1.2 现有路线和它们的代价

| 路线 | 代表工作 | 如何从经验里得到信号 | 代价 / 问题 |
|---|---|---|---|
| 只学成功 | RFT / STaR / ReST（拒绝采样微调） | 只用自己成功的轨迹 | 浪费失败；我们的同预算实验里多轮也明显落后（§6.2） |
| 在线 RL | GRPO、GiGPO、BEACON（里程碑奖励塑形）、SERL（事后自蒸馏 + GRPO） | 大量在线 rollout + 奖励 / 优势 | 样本和算力大：原文约 1.9 万局轨迹、8 张 A100-80G / H200 约 10 小时 |
| 不验证的自蒸馏 | HINT-SD（失败步上的事后自蒸馏） | 模型自己挑失败步、自己写反馈、蒸馏到这些步 | 纠正**不经验证**，原文局限部分承认"信号取决于反馈是否正确" |
| MC rollout 验证 | IPR 式步级价值；我们的 rollout 基线 | 从候选状态 rollout 到结束看输赢 | 每个候选最多约 50 次模型调用；噪声大（依赖学生后续行为） |
| 专家对比 | ETO | 失败 vs 专家轨迹做 DPO | 需要目标环境的专家示范，不是纯自进化 |
| 更强老师 | 蒸馏、FTB（用 32B 老师判断老师的指导） | 大模型给纠正或判断 | 不自给自足，不高效 |

### 1.3 我们的三个关键观察（都有数据，见 §6）
1. **一个可信的单步纠正，信息量很大：**
   - 只用失败里最可信的 20% 纠正（82 条）加 100 条自身回放，774 局从 416 提到 **537**（R1）。
   - 同样的训练样本数，只模仿自己的胜局只能到 481。
2. **一步环境反馈比完整 rollout 更好、也便宜得多：**
   - 同样的选步和候选：一步证据 547 vs rollout 508（R1，p=0.0002），R2 572 vs 485（p=8e-15）。
   - 验证成本：820 次环境步、0 次模型调用，vs 32,559 次环境步、每步一次模型调用。
3. **一个小的、跨领域的、冻结的归因器足够选步：**
   - 3B Model A 只在 Who&When Pro 上训练（ALFWorld 部分整体留出），在 ALFWorld 上的步准确率约 64%，从不更新。
   - 用它选步的链每轮都显著增长。
   - 而每轮重训归因器的旧方案要多花约 3 小时，并且不更新就会停滞（§6.3）。

### 1.4 贡献（写进 Introduction 末尾）
1. **方法：** 一个把失败变成**环境验证的单步自我纠正**的自进化流程：冻结归因器选步 → 事后自我老师提候选 → 一步目标进度证据筛选 → 少量纠正 + 自身回放训练。
2. **一步目标进度证据：** 一个任务无关的打分方式（目标条件被定位 / 满足 / 违反的变化）。各环境只需定义"条件是什么、怎么从观察读状态"。
3. **结果：** 多轮显著增长（R0 → R1 → R2【→ R3 待填】）。在同样的环境交互预算下优于 RFT、rollout 验证、不筛选，以及不验证的自蒸馏（HINT-SD 式）【HINT-SD / SERL 待填】。
4. **效率：** 每轮约 150–180 条训练样本、约 5 个 A100 GPU 小时；全程没有比学生更大的模型；验证不需要模型调用。

## 3. 方法（Method，按这个顺序写）

### 3.1 设置与记号
- **环境：** 文本 ALFWorld，每局最多 50 步，每步从**可执行命令列表**中选一个动作。
- **学生 $\pi_\theta$：** Qwen2.5-3B-Instruct + LoRA（r=32, α=64, dropout 0.05, 全部线性层）。$\pi_0$ 是在 100 条专家轨迹上 SFT 1 个 epoch 的起点。每轮在同一个 LoRA 上继续训练。
- **轮次：** $r = 1, 2, 3, \dots$；第 $r$ 轮从 $\pi_{r-1}$ 出发。
- **指令：** $g$；观察历史：$h_t$；第 $t$ 步执行动作 $a$ 后的观察：$o'$。

### 3.2 一轮流程（Algorithm 1，图 1 画的就是这个）
```
输入：上一轮学生 π_{r-1}，冻结的归因器 A（3B Model A）
1. 收集：π_{r-1} 在训练局 0–1499 上各玩一局（温度 1.0，最多 50 步）
   （R1 例外：复用 SFT 学生已有的 1323 局收集）
2. 失败集合 F = 前 1000 局里的失败局
3. 选步：对每个失败 τ ∈ F，A 输出关键错误步 t*(τ) 和错误类型（诊断）
4. 事后自我老师：π_{r-1} 在 h_{t*} 上，额外看到 [失败局 t* 之后发生的事 + A 的诊断 + 自己写的分析]，
   给所有可执行命令打分；候选 = 除原动作 a⁻ 外得分最高的 2 个
5. 一步证据：把失败局重放到 t*，每个候选执行一步，计算 F(h_{t*}, a)（§3.5）
6. 选择：每个状态留 F 最高、F > 0 的候选；所有状态按 (F, 老师概率) 排序，取前 K = round(0.2 · |F|) 个
7. 训练：K 条 one-hot 纠正 + 100 条自身回放，1 个 epoch → π_r
8. 评测：774 局，贪心
```

### 3.3 选步：冻结的 3B 失败归因器（Model A）
- **模型：** Qwen2.5-3B-Instruct + LoRA（r=16, α=32），3 epoch，lr 1e-4。
- **训练数据：** Who&When Pro 官方文本版 6,257 条（8 个多智能体框架）。**ALFWorld 的 311 条整体留出**；其余 7 个框架实际训练 5,016 条（smolagents、mathchat、magentic-one、debate、macnet、dylan、metagpt）。
- **输入：** 删掉环境返回内容（"no observations" 格式），只保留 agent 的思考和动作。这一格式让 ALFWorld 留出集的步准确率从 53.4% 升到 **64.3%**（7B 同格式为 91.3%）。
- **输出：** 关键错误步 $\hat t$ + 17 类错误模式之一；$t^* = \text{clip}(\hat t, 0, |\tau|-1)$。
- **从不更新。** 依据：旧方案每轮用环境标签重训归因器，每轮多花约 3 小时，重训后的归因器在注入错误的测试集上还不如"永远猜同一步"。不重训时（R2 用 A0）链会停滞（486 vs 531，p=3e-5）。冻结的 Model A 不需要任何训练，链照样每轮增长。

### 3.4 事后自我老师（hindsight self-teacher）
- **老师 = 当前学生 $\pi_{r-1}$ 自己。** 没有更大的模型。
- **两次调用：**
  1. 生成一段分析（"这次失败了，为什么，在这一步该怎么做"）；
  2. 在附加 [事后信息 + Model A 诊断 + 分析] 的上下文中，给 $h_{t^*}$ 的所有可执行命令打分。
- **候选：** 排除原动作 $a^-$ 后的前 2 个命令。

### 3.5 一步目标进度证据（核心，公式这样写）
**目标条件：** 指令定义一组目标条件 $C(g)$。每个条件在历史 $h$ 下有一个可观测状态：
$$\sigma_c(h) \in \{0\ \text{(未观察到)},\ 1\ \text{(已定位)},\ 2\ \text{(环境已确认成立)}\}$$

**目标进度：**
$$\Phi_g(h) = \sum_{c \in C(g)} \sigma_c(h), \qquad \Phi_g(h) = -\infty \ \text{若 } h \text{ 中发生了不可逆失败}$$

**一步证据：**
$$F(h_t, a) = \Phi_g\big(h_t \oplus (a, o')\big) - \Phi_g(h_t) \;-\; \kappa \cdot \mathbb{1}\big[o' \text{ 没有新信息}\big]$$

$F$ 相同时，依次按新内容数 $|N(a)|$、老师概率打破平局。

**等级（只用顺序）：** 完成 ≻ 满足一个条件 ≻ 定位一个条件 ≻ 只有无关新信息 ≻ 无变化（付 κ）≻ 不可逆违反。
- **实现编码：** $2\,\text{loc} + 2\,\text{sat} + \tfrac{1}{5}\min(|N|, 5) - 2\,\text{nul} - 4\,\text{vio}$。
- **验证过：** 纯等级排序在 R1 / R2 / R3 选出的纠正**完全相同**（164/164、110/110、102/102），所以权重不是需要调的超参数。

**各环境的实例化（表 X，放正文）：**

| | ALFWorld | WebShop |
|---|---|---|
| $C(g)$ | 任务物体、状态变化、目的地 | 类别、属性词、选项值、价格上限 |
| $\sigma: 0 \to 1$ | 任务物体首次出现在观察中 | 结果页出现标题匹配的商品 |
| $\sigma \to 2$ | 环境确认对任务物体的改变（"You pick up / clean / put the X"），且不是重复动作；或任务成功 | 商品页提供所需选项、价格不超上限、有属性词；选中所需选项；购买且奖励 = 1 |
| 不可逆失败 | 无（ALFWorld 没有不可逆的单步动作） | 购买且奖励 < 1 |
| 无新信息 | "Nothing happens"、回到看过的地方 | 页面不变、回到看过的页面、打开不合格的商品 |

**例子**（任务 "put a clean soapbar in cart"，画进图 1 的放大框）：

| 候选动作 | 环境返回 | 等级 |
|---|---|---|
| go to countertop 2 | "… you see a cloth 1, a soapbar 1 …" | 定位（保留） |
| take soapbar 1 from countertop 2 | "You pick up the soapbar 1 …" | 满足（保留） |
| examine shelf 1 | "Nothing happens." | 无变化（过滤） |

### 3.6 预算化选择、回放与训练
- **预算：** $K = \text{round}(0.2 \cdot |F|)$，$|F|$ 是本轮前 1000 局中的失败数。学生变强时纠正数自动减少（R1：410 → 82；R2：271 → 54；R3【待填】）。
- **回放：** 固定 100 条。取本轮自己赢的局中最短的 50 局，每局随机 2 步（跳过 look / inventory / help），SFT 目标 = 当时的动作。
- **损失：**
  - 纠正样本：可执行命令集上的 one-hot KL，即对目标命令的交叉熵 $-\log q_\theta(a^* \mid h)$；
  - 回放样本：动作文本的 token 级负对数似然。
- **优化：** AdamW，lr 1e-5，batch 8，1 epoch。逐样本反传 + fp32 梯度累积 + 非有限梯度跳过。

### 3.7 每轮成本（写进"效率"小节）
| 项 | 每轮 |
|---|---|
| 环境收集 | 1500 局（R1 复用 1323 局） |
| 归因器调用 | 每个失败 1 次生成（约 270–420 次） |
| 老师调用 | 每个失败状态 2 次前向 |
| 一步验证 | 2 个候选 × (前缀重放 + 1 步)，CPU，**0 次模型调用** |
| 训练样本 | 约 150–180 条（20% 纠正 + 100 回放） |
| GPU 时间 | 约 5 个 A100-40G 小时（收集占大头） |

## 7. 局限（Limitations 节）
1. **环境：** 目前只有 ALFWorld 有完整结果；WebShop 的条件解析依赖其固定指令句式；AppWorld 还没测。

3. **种子：** 单种子，主结果需要补 3 种子。
4. **起点：** 需要一个 SFT 起点（100 条示范），所有基线共用。
5. **一步证据看不到长程影响：** 有偏，但方差低；rollout 方差高、成本高。
