# 每个结果用的方法（2026-10-10 01:40 整理）

记号：
- **默认配方** = 3B Model A（不看观察）选步 + 标准视角老师 + 每个失败取老师 top-2（排除原动作）+ 通用一步证据 + env_top 筛选（S>0，无 margin）+ K = round(ρ·前 1000 局失败数) + 回放 100 步 + 1 epoch LoRA（lr 1e-5，batch 8，seed 0）。
  - 标准视角老师：前缀窗口 10 步，后续 25 步，观察截 160 字，附 Model A 的步和类别，加 3 句分析。
  - 回放：50 局最短胜局 × 2 步。
  - 修正损失：在可选命令上的交叉熵。
- **新配方** = 完整视角老师（完整前缀、全部后续、完整观察）+ margin 规则（修正分数须严格高于原动作）+ fail_weighted 回放（按失败任务类型分配名额，用完整最短胜局填充）。
- 评测：ALFWorld 774 局（valid_unseen 134 + valid_seen 140 + 留出 train 1500–1999 共 500）；贪心；配对 McNemar。

## ScienceWorld（3B 生成式学生；R0 = student10：每类任务最多 10 条金标准示范，实际 290 条轨迹（12,358 对），3 个 epoch，lr 1e-4（据 sft_student10.log，10-10 15:30 核对））
- **评测：** 848 局 = test（每类最多 30 个，651 局）+ dev（每类 7 个，197 局）；上限 50 步；贪心；安全替换规则（`--snap safe`，修复了 10-04 的 fuzzy 替换 bug）。
- **收集：** 每轮 518 局（train 每类最多 20 个变体，seed 1，每轮相同），温度 T=1.0，top-k 20，重复惩罚 1.05。
- **其余：**
  - K = 20% × 失败数；
  - 3B Model A（不看观察）选步；
  - 生成式老师：8 个采样，按老师对数概率取前 2；
  - 通用一步证据，用原生分数，并剔除任务描述文本；
  - env_top 筛选；
  - 修正用动作文本的逐 token 交叉熵；回放 100 步。
