# ScienceWorld StepFix 最终汇总（2026-10-10 18:20）

## 评测设定
- **评测集：** 848 局 = test 651（每类最多 30 个，seed 0）+ dev 197。贪心，50 步上限，`--snap safe`。
- **训练收集：** 518 个 train 变体（per_task 20，seed 1；有些任务不足 20 个变体），每轮都用 seed 1。
- **统计：** 配对精确 McNemar。平均分把负分按 0 计。
- **R0：** student10。每类最多 10 条金标准示范，实际 290 条轨迹（12,358 对），3 个 epoch，lr 1e-4。
- **训练噪声：** r2a 和 r2s3 的 63 条修正有 54 条相同、回放也相同，结果仍相差 13 局。所以 ±15 局以内属于训练噪声，未跑多种子。

## 要点
1. **第一轮显著提升，** 并且显著优于随机选择和同数据量的 RFT。
2. **之后各种配方都停在 289–308 之间。** 修正加到 3 倍（r1big，185 条强修正）也没有突破，说明瓶颈不在修正数量。
3. **放进弱修正的方案后期都会退化：** 40% 名额、3 步观察、不筛选、随机选择。
4. **同样的局数下，在线 RL 在第一阶段没有提升；** 后续检查点正在评测。
